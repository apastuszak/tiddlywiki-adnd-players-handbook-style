# Jost Handbook for TiddlyWiki

Give your TiddlyWiki an AD&D 1E Player’s Handbook–inspired appearance, with Jost fonts, bold headings, and striped tables.

## Install

1. Download **Jost-Handbook-TiddlyWiki-Updated.json**.
2. Open your TiddlyWiki and drag the JSON file onto the page.
3. In the import screen, select all **24 tiddlers** and click **Import**. If updating an earlier installation, allow the matching tiddlers to be replaced.
4. Save your wiki.

The styling applies automatically. The fonts are embedded in your wiki and work offline.

## Use

Write and edit tiddlers normally in WikiText or Markdown. Markdown requires TiddlyWiki’s Markdown plugin.

Regular text uses **Jost Compact J Book**. Bold and italic formatting select the corresponding font styles automatically. Tables have bold black headers on white, with body rows alternating between three gray rows and three white rows.

## Choose a layout

Open the tiddler named **Handbook Layout**. Use the sidebar search to find it.

Select **One column** or **Two columns**. The choice applies throughout the wiki immediately. Save your wiki to keep your selection. Tables span both columns in the two-column layout.

## Updating

Import a newer version of the JSON file, allow replacements, and save. An update may reset the layout to one column, so check **Handbook Layout** afterward.
