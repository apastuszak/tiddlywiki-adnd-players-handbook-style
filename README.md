# tiddlywiki-adnd-players-handbook-style

This is a JSON file you can import into TiddlyWIki to make it look like the 1E Player's Handbook.

This embeds a modified version of the open source font Jost and some style sheets to make tables look like AD&D 1E tables.

The style support 1-column layout and 2-column layouts.
